# Simple GUI Chat — WebSocket Server

Multi-user room relay for the React Native app.

## Features

- Auth + multi-user rooms
- Classic legacy `join` as `gaitonde` / `bunty`
- Typing indicators
- Delivery/read receipts
- Media message passthrough (`mediaUri`)
- In-room **ChatBot** (`bot-lounge`, `@bot`, slash commands)

## Run

```bash
npm install
npm start
```

Port **6001**.
